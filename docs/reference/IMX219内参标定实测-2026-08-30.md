# IMX219 内参标定实测（2026-08-30）

## 结论

当前 Jetson `sensor-id=0` 的 IMX219、当前镜头模组、Argus 1920×1080 模式已完成 Q12-70-5
内参标定和人工 undistort 对比，production 文件为：

```text
configs/camera/imx219_1920x1080_2026-08-30.yaml
```

状态：`VERIFIED`。该结论只适用于当前模组/镜头和 1920×1080；更换摄像头、镜头、sensor mode、
裁剪或缩放策略后必须重新标定。

## 数据集

- 相机：IMX219，`nvargus://0`
- 分辨率/帧率：1920×1080@30
- 标定板：DAFAN VISION Q12-70-5，12×9 格、11×8 内角点、5 mm 方格
- 视频：`01_spatial.mp4`、`02_yaw.mp4`、`03_pitch.mp4`、`04_scale.mp4`、`05_mixed.mp4`
- 数据目录：`_output/datasets/camera-calibration/q12-imx219-2026-08-30`
- 数据集校验：目录内 `SHA256SUMS`

## 复现命令

```bash
_output/build/arm64-debug/bin/camera-calibrator \
  --board-profile q12-70-5 \
  --frames 30 \
  --max-candidates 50 \
  --input-video _output/datasets/camera-calibration/q12-imx219-2026-08-30/01_spatial.mp4 \
  --input-video _output/datasets/camera-calibration/q12-imx219-2026-08-30/02_yaw.mp4 \
  --input-video _output/datasets/camera-calibration/q12-imx219-2026-08-30/03_pitch.mp4 \
  --input-video _output/datasets/camera-calibration/q12-imx219-2026-08-30/04_scale.mp4 \

  --output-dir _output/runtime/camera-calibration/q12-imx219-2026-08-30-offline-final
```
