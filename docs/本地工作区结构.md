# 本地工作区结构

Jetson 开发工作区固定按源码、模型、第三方依赖和运行产物分开：

```text
/home/nvidia/code/
├── github/
│   ├── cockpit-system/              主项目
│   └── chassis-controller/          STM32 下位机项目（存在时）
├── models/
│   ├── asr/
│   │   └── sherpa-onnx-sense-voice-zh-en-ja-ko-yue-int8-2024-07-17/
│   ├── tts/
│   │   ├── matcha-icefall-zh-baker/
│   │   └── vocos-22khz-univ.onnx
│   └── downloads/                   模型原始下载包
└── third_party/
    └── sherpa-onnx/                  sherpa-onnx 源码
```

## 放置规则

- 项目源码和受 Git 管理的文档只放在 `github/cockpit-system`。
- ASR、TTS 模型放在 `models/asr` 和 `models/tts`，原始压缩包放在
  `models/downloads`；不要把大模型提交到项目仓库。
- Sherpa-ONNX 外部源码放在 `third_party`；项目 gRPC/Protobuf 使用系统包。
- 项目构建、测试、实验和运行产物统一放在
  `github/cockpit-system/_output`。
- 语音实验源码和构建目录放在 `_output/experiments/sherpa-onnx`。
- 本地生成的 WAV 放在 `_output/runtime/audio`，运行日志放在
  `_output/runtime/logs`。
