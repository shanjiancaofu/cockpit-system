# 本地工作区结构

Jetson 开发工作区固定按源码和运行产物分开：

```text
/home/nvidia/code/
├── github/
│   ├── cockpit-system/              主项目
│   └── chassis-controller/          STM32 下位机项目（存在时）
└── models/                           独立实验资源，不进入产品构建
```

## 放置规则

- 项目源码和受 Git 管理的文档只放在 `github/cockpit-system`。
- 项目构建、测试、实验和运行产物统一放在
  `github/cockpit-system/_output`。
- 本地生成的 WAV 放在 `_output/runtime/audio`，运行日志放在
  `_output/runtime/logs`。
