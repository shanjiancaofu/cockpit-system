## 当前口径

- 720p30 是正式 V1 Software ISP baseline；1080p30 是质量模式。
- 3280×2464 RAW10 可达30FPS但CPU约246%，不作为正式实时模式。
- V1固定使用公开C API已验证的WenetSpeech 2024 mobile chunk-16模型；2025 chunk-8模型只用于兼容性复现。
- 生产KWS开启后的20分钟整机Gate已完成，没有再次出现direct-listening环境请求风暴。
- Gate中audio_driver曾发生一次SIGSEGV并由Navigator恢复；随后5分钟4轮TTS复验未复现。该项按真实结果保留为Freeze blocker，不声明无条件Full-System PASS。
- UI模式与ROS2 minimal test stack并发运行；ROS2使用 fake odom/scan/chassis，不产生真实CAN运动输出。
