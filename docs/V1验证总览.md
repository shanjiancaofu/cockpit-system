## 当前口径

- 720p30 是正式 V1 Software ISP baseline；1080p30 是质量模式。
- 3280×2464 RAW10 可达30FPS但CPU约246%，不作为正式实时模式。
- KWS 未通过前，不声明“真实麦克风唤醒词全链路 PASS”；当前整机测试使用 KWS disabled/direct listening。
- KWS disabled 的direct-listening soak已证明不是可接受的生产替代：17分钟时可用内存约548MiB、swap约1.31GiB，因此提前FAIL。
- UI模式与ROS2 minimal test stack并发运行；ROS2使用 fake odom/scan/chassis，不产生真实CAN运动输出。
