## 维护规则

- 文档与代码冲突时，以当前代码和测试为准，并同步修正文档。
- 合并文档时先迁移独有内容，再删除重复段落；历史内容不因当前方案变化而改写。
- 每次对话只读取上表对应的最小文档集合。
- 提交前运行 `pre-commit run --all-files`。
- `example/` 和 `reference/` 保持原始参考内容，不作为当前实现依据；当前事实、下一步和历史分别以
  `实现状态.md`、`项目进度总览.md`、`变更记录.md` 为准。
