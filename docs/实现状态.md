## 状态分级

| 状态 | 含义 |
|---|---|
| 已落地 | 已有代码、构建通过，并进入 smoke 或单元测试 |
| 可用原型 | 主链路可跑，但还缺真实硬件、真实性能或异常场景验证 |
| 部分完成 | 有基础模块或接口，主链路尚未闭环 |
| 待实现 | 只有规划或占位，没有可用代码 |

## 当前验证基线

当前开发基线为 Ubuntu 22.04 x86_64 VM；实机基线为 Jetson Orin Nano Super、L4T R36.4.3、
GCC 11.4、CMake 3.22 和 Qt 6.2。WSL-R1 至 WSL-R4 保留为历史可靠性证据，不作为当前 VM 的命名。

```bash
bash scripts/build.sh
bash scripts/build.sh --type release
bash scripts/tests/smoke.sh
bash scripts/tests/wsl-matrix.sh
pre-commit run --all-files
```

当前 Ubuntu 22.04 x86_64 VM correctness 基线：Debug/Release CTest 91/91、Navigator smoke、typed
ChassisEvent→Sentinel fake 闭环、Voice/Media 实际状态时序 smoke、LLM 2B/4B pinned smoke 和
pre-commit 通过。可选 ROS2 Debug integration、四个 cockpit ament package、固定 revision 的外部
`rplidar_ros` package、官方 Nav2 correctness
故障矩阵和隔离 action disconnect/recovery smoke 通过。ASan/UBSan 非
system-gRPC 集合 66/66 通过；Media 的纯模型测试与真实 gRPC 集成测试
已拆分，Qt 6.2 software/offscreen 的进程退出缓存只在对应 QML ASan 测试中精确抑制。当前 VM 使用
统一 CTest launcher 仅对 TSan 测试进程关闭 ASLR，避开 Linux 6.8 shadow-memory 映射冲突；正式
Camera/Audio/Agent/Qt 模型集合使用 Clang 14 TSan，避免 GCC 11 对 steady-clock condition-variable
wait 丢失 mutex ownership 的误报，12/12 通过。以下 WSL-R1 至 WSL-R4 数字均为历史证据：历史独立 Debug/Release

smoke 通过；该数字是当时测试清单，不与当前 WSL 测试总数强行对齐。语音测试覆盖连续命令顺序、
主动中断当前 action、丢弃排队 transcript、provider 超时和失败后继续服务。Navigator 测试覆盖有界 IPC、模式切换、
`cockpit-ctl runtime`、显式重启、整组 reload、真实 development 模块健康采样、camera driver 崩溃恢复、

已验证：IMX219 Argus/NVMM 实际采集、Qt 预览、JPEG 拍照、两分钟 4146 帧和正式 systemd
7 分 33 秒 13599 帧零丢帧，以及 no-frames 故障恢复。
