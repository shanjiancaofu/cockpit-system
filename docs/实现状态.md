## 状态分级

| 状态 | 含义 |
|---|---|
| 已落地 | 已有代码、构建通过，并进入 smoke 或单元测试 |
| 可用原型 | 主链路可跑，但还缺真实硬件、真实性能或异常场景验证 |
| 部分完成 | 有基础模块或接口，主链路尚未闭环 |
| 待实现 | 只有规划或占位，没有可用代码 |

## 当前验证基线

开发机环境：WSL2 Ubuntu 22.04，GCC 11.4、CMake 3.22、Ninja 1.10、Qt 6.2。

```bash
bash scripts/build.sh
bash scripts/run_smoke.sh
bash scripts/run_wsl_matrix.sh
pre-commit run --all-files
```

最近基线：x86_64 Debug 全量 44/44 CTest 和 Navigator 单入口完整 smoke 通过；Navigator 测试覆盖模式切换、
`cockpit-ctl runtime`、显式重启、整组 reload、真实 development 模块健康采样、camera driver 崩溃恢复、
HMI/UI 双向崩溃恢复、重启限制和 ABI 不兼容拒绝。safe-ota 测试覆盖候选确认、SHA256、独立安装、
真实 upgrade mode、事务中断恢复、健康检查和失败回滚。WSL 矩阵覆盖配置边界、Release 双版本、包篡改
拒绝、临时安装、配置保留、mode health、gateway 断流恢复、recording 不可达、队列满、shared-memory
writer 重启和 rollback，并输出 `_output/runtime/reports/wsl-matrix.json`。

这条基线表示 WSL 原型具备自动验证证据，不表示真实 TTS、HMI 媒体控制、云端上传、Jetson 硬件或
量产升级已经完成。whisper.cpp 模型测试仅在显式配置模型时进入测试集。

## 明确未验证

- Jetson 实机部署、systemd 长运行和硬件权限。
- 真实车辆 CAN、GPIO、I2C 等外设。
- 真实麦克风、扬声器、AEC 和噪声环境。
- CSI 摄像头、Jetson GStreamer pipeline 和长时间预览稳定性。
- whisper.cpp Jetson CUDA/TensorRT 性能。
- MQTT/TLS/鉴权、量产 OTA、崩溃收集和云端平台。
